## What Is This?

This knowledge base documents the **Loomi Connect AI Hackathon 2026** — Bloomreach's first external AI hackathon, where teams worldwide built AI agents on top of Loomi Connect MCP.

- **102 teams registered** across **29 countries**
- **25 teams submitted** final projects
- **89 MCP tools** available across 3 servers
- Run entirely using Claude as the operating system
